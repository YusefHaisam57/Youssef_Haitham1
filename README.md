## Publish on GitHub Pages
1. Upload all files and folders to the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.

Keep all folders intact when uploading; the HTML pages reference files in `assets/`.
